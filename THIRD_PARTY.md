# Third-party components

The experimental standalone writer uses:

- The new `native/proof-text.mjs` point-text constructor and `native/proof-defaults.json` are adapted from `vurglepuddle/PROOF`, `src/extension/internal/ai/ai-native-writer-text.cpp`, commit `d822dc5dea265675a0fd5dec550e3e0dcd5988f0`, licensed GPL-2.0-or-later: https://github.com/vurglepuddle/PROOF/blob/d822dc5dea265675a0fd5dec550e3e0dcd5988f0/src/extension/internal/ai/ai-native-writer-text.cpp . These adapted components retain that license; a distribution combining them with the exporter must satisfy GPL-2.0-or-later. Include this notice, corresponding source and `LICENSES/GPL-2.0.txt`. This does not relicense upstream MIT dependencies, whose notices remain applicable. No PROOF/Illustrator user files or application presets are distributed.

- The Rust writer in `plugin/src/native.rs` also adapts the frame/text-resource, gradient-record, clipping and opacity-mask structures from the same pinned PROOF commit: `ai-native-writer-text.cpp`, `ai-native-writer-gradient.cpp` and `ai-native-writer.cpp`. It is GPL-2.0-or-later and is distributed with corresponding source and the same notices. Arrow symbols are our own elementary geometry, not Adobe presets.

- `ai-file` 0.1.0, MIT, copyright 2026 Lucas Goncalves: https://github.com/goncalveslucasv/ai-file . Its document template, Txt2 serialization, and documented numeric field meanings are reused for native data. Its own read/write tests do not establish Illustrator compatibility.
- `pdf-lib` 1.17.1, MIT: https://github.com/Hopding/pdf-lib . Adds the native editing stream to the real PDF preview generated by VectorCraft, so Unicode preview text is not replaced with Helvetica.
- `pngjs` 7.0.0, MIT: https://github.com/pngjs/pngjs . Decodes PNG samples for embedded native raster objects.
- `fontkit` 2.0.4, MIT: https://github.com/foliojs/fontkit . Used for standalone font discovery and glyph-coverage preflight; fonts themselves are read locally and are not included in the repository or packages.

Versions and integrity hashes are pinned by package-lock.json. Distributions that include dependencies must include their LICENSE files. No Adobe application binary or user artwork is bundled.

The Rust/WASM implementation uses serde_json, base64, image 0.25.9 (PNG/JPEG/WebP decoders; MIT OR Apache-2.0) and their transitive Rust dependencies, pinned in plugin/Cargo.lock. Release ZIPs include the vendored dependency sources and their original license files under plugin/vendor, plus plugin/vendor-config.toml for an offline Cargo build. The normal online source build uses Cargo.lock; no user fonts or Adobe symbols are included.
